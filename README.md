# 🥗 FridgeMate - Smart Kitchen Assistant

**Reduce food waste. Manage your groceries. Discover what to cook.**

FridgeMate is an Android application designed to make kitchen and food inventory management easier. It helps users keep track of food items, discover recipes based on available ingredients, and stay aware of products that may be nearing their expiry dates.

The goal is to simplify everyday meal planning, encourage smarter grocery management, and reduce unnecessary food waste.

## 🎯 Problem Statement

Managing food at home can be challenging. People often forget what is stored in their refrigerators, overlook expiry dates, and struggle to decide what to cook with the ingredients they already have. This can lead to food waste and unnecessary grocery purchases.

FridgeMate aims to address these challenges by providing a convenient digital solution for managing kitchen inventory and planning meals.

## ✨ Key Features

- **🧊 Food Inventory Management** - Keep track of food items stored in your kitchen.
- **🍳 Recipe Suggestions** - Explore meal ideas based on available ingredients.
- **⏰ Expiry Awareness** - Help identify food items that may be approaching their expiry dates.
- **🛒 Smarter Grocery Management** - Make better use of existing ingredients before purchasing more.
- **♻️ Food Waste Reduction** - Encourage responsible food consumption and more efficient kitchen management.
- **📱 Android Experience** - Access kitchen management features through a mobile application.

*Feature availability depends on the current implementation of the application.*

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Platform:** Android
- **UI Development:** Jetpack Compose
- **Build System:** Gradle with Kotlin DSL

## 🚀 Getting Started

Follow these steps to explore the project locally.

### Prerequisites

- Android Studio
- Android SDK
- JDK version compatible with the project's Gradle configuration
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Raksha451/FRIDGEMATE.git
   ```

2. Navigate to the project directory:

   ```bash
   cd FRIDGEMATE
   ```

3. Open the project in Android Studio.

4. Allow Gradle to sync and download the required dependencies.

5. Connect an Android device or start an Android Emulator.

6. Build and run the application from Android Studio.
